## Disco Tray Reflection 09-17

I started this week by creating a repo for the SocialHX website, and I then forked this repository. Early in the week, I created the initial ASP.NET Razor Page and Redgate Database Schema to present to Dr. Kennedy. We established that the tables we will use are: Student, Prescriber, Prescription, Activities (Events), Prescribed Events, Follow Up Week 1, and Follow Up Week 4. We initially did not have the Week 1 and Week 4 follow up tables before the meeting with Dr. Goadrich and Dr. Kennedy, in which we then revised this mistake.

Later in the week, after initializing the ASP.NET Razor Page, we implemented the backend data base by creating .cs files for each table in the "Model" folder. After some tedious corrections with the foreign keys, we finally made migrations and scaffolded the data schema, which is now accessible on the webpage. During my creation for the Hendrix Advancement webpage last semester, my primary job was dealing with the front end HTML and CSS code. This restricted me from working with the creation of the backend database, so this experience was great for me to have, as I now understand how to correctly implement the database myself! I also learned to not use any underscores ever again in dotnet razor pages...
